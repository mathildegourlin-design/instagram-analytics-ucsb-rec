# Instagram Analytics — UCSB Department of Recreation

## Live Reports
- [Spring 2026 Analysis](https://mathildegourlin-design.github.io/instagram-analytics-ucsb-rec/ucsb_rec_spring_analysis.html)
- [Winter 2026 Analysis](https://mathildegourlin-design.github.io/instagram-analytics-ucsb-rec/ucsb_rec_winter_analysis.html)


Quarterly social media performance analysis for the UCSB Department 
of Recreation Instagram account (~10,600 followers), built in R with 
tidyverse and presented to department stakeholders.

## What this project covers
- Post-level performance analysis across 70+ posts per quarter
- Engagement rate, reach, views, and follower growth tracking
- Media type comparison (video vs. carousel vs. image)
- Day-of-week and time-of-day posting pattern analysis
- Correlation analysis between content variables and performance
- Custom UCSB-branded ggplot2 theme for all visualizations

## Quarters analyzed
- Fall 2025 
- Winter 2026
- Spring 2026

## Tools and packages
`R` `tidyverse` `ggplot2` `lubridate` `patchwork` `knitr` 
`kableExtra` `ggtext` `scales` `corrplot`

## Skills demonstrated
- Real-world social media data extraction and cleaning
- Exploratory data analysis and pattern recognition
- Stakeholder-ready reporting with branded visualizations
- Quarterly trend analysis and strategic recommendations

## Data source
Raw post performance data exported from Later analytics platform,
cleaned and structured for analysis in RStudio.
